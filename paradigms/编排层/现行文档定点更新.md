# 同步进度、沉淀经验或整理交接文档

**现行做法**:按[全局契约](../../global/AGENTS.md)更新现行事实,由 [maintain-project-context](../../global/skills/maintain-project-context/SKILL.md) 路由到项目已有的队列、手册与证据记录。替换过时内容,长过程留在证据层,不为每次对话新增长期文档。

**原则**:入口帮助下一次行动,证据保留可追溯性,两者各写一次。

**适用范围**:项目进度与协作上下文维护;不限制技术文章、科研原始记录的必要篇幅,普通代码修复不触发全库整理。

**Claude 与 Codex**:共享同一份 skill 与全局契约;新会话的实际触发需分别核验。

**落实与验证**:Orrery 的 `global/`、`scripts/context-check.mjs` 与 HomeLab Control 的 `AGENTS.md` 接入;自动检查覆盖链接、篇幅提示与分发。实际节省 token、减少返工的效果待后续真实任务核验。

**来源**:本仓库实践 · 核实于 2026-09-30
