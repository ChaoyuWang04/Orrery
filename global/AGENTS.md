# 全局协作守则

我在任何项目里与 Claude、Codex 协作都适用。项目自己的 `AGENTS.md` 或 `CLAUDE.md` 与本文件冲突时,以项目为准。真源在 `~/1Project/interviewprep/global/`,由该仓库的 `scripts/link-global.sh` 链接到用户级,改这里不改链接。

## 模糊就拷问

我的话能读出两种以上做法、选错要返工时,当场停下来问:任务开头、做到一半、收到我的反馈时都一样。

- 能查到的事实自己查(读文件、派子 agent),只问只有我能定的决策
- 按轮问:一轮问完互不依赖的问题,每问附推荐;我回「好」即采纳本轮全部推荐,「按推荐收」则剩下的都取推荐
- 选错也不费事的小模糊,取默认做法,在回复里写一句
- 要问好几轮时,读 grilling skill

问决策不算请示。请示是把该你下的判断推回给我,比如「要不要继续」「这样可以吗」;确认过的范围内一路做完。
