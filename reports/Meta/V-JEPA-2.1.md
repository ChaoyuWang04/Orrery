# V-JEPA 2.1：稠密特征糊掉，是因为看得见的图块从来没被考过

<!-- release-date: 2026-03-16 -->

> 本文依据 FAIR at Meta 的 **V-JEPA 2.1: Unlocking Dense Features in Video Self-Supervised Learning**，即 arXiv:2603.14482v3（2026-06-11 修订，封面日期 2026-06-12），共 37 页。页码均指 PDF 自身的页码。文中会区分三件事：**报告明确写了什么**、**我们怎么解释它**、**哪些是外部资料或本文推算**。

## 读前先把几个词说成人话

这篇论文难读的地方不在公式，而在它把「掩码预测」这件大家习以为常的事，拆成了「考哪些位置」这个问题。后面所有表，都踩在这一问上。

- **自监督学习（Self-Supervised Learning，SSL）**：不用人工标签，让模型从数据自身造题来学表征。比如遮住一部分画面，让模型猜被遮的是什么。
- **JEPA（Joint-Embedding Predictive Architecture，联合嵌入预测架构）**：猜的不是像素，而是「被遮部分在表征空间里长什么样」。标准答案由另一个编码器给出，这个编码器是在线编码器参数的指数滑动平均（EMA），并且停止梯度，防止表征塌成常数。
- **图块 / token**：图像被切成 16×16 像素的小块，视频再在时间上每 2 帧并成一个「时空管」，每一块变成一个向量，叫 token。
- **上下文 token（context token）**：掩码之后仍然看得见的那些块。
- **稠密特征（dense features）**：不是整张图一个向量，而是每个图块都有一个向量。深度估计、语义分割、目标跟踪、「下一秒要抓哪里」，用的都是这张特征图。
- **全局特征**：把整段视频或整张图压成的判断，比如「这是在倒水」。动作识别、图像分类用它。
- **线性探针 / 注意力探针**：冻住编码器，只在上面训一层线性层或几层小注意力网络，测表征本身好不好用。
- **寄存器 token（register token）**：一组不对应任何图像位置、专门用来攒全局信息的向量。它来自 DINOv2 那一系的观察：ViT 会自发拿某些图块当草稿纸。

论文自己的四个新名字：**稠密预测损失（Dense Predictive Loss）**、**深层自监督（Deep Self-Supervision）**、**多模态分词器（Multi-Modal Tokenizer）**、**VisionMix163M 数据集**。

前作是 V-JEPA 2（见 V-JEPA-2 一篇）。那一篇的世界模型不是像素生成器，而是一套表征空间里的预测器；2.1 不推翻它，只补它表征里缺的那一块。

## 一句话先说清

V-JEPA 2 的全局运动理解已经很强，但把每个图块的特征拿出来做主成分分析（PCA）上色，得到的是一张彩色噪点图（PDF p.1、p.4）。线性探针把这张噪点图写成数字：ADE20K 分割只有 22.2 mIoU，NYUv2 深度的均方根误差 0.682（PDF p.4、p.7）。**局部信息很难从 2.0 的表征里读出来。**

论文的诊断只有一句（PDF p.4）：损失只加在被遮住的 token 上，模型就没有动力在看得见的 token 里保留局部信息，它可以把这些位置挪去攒全局信息——就像寄存器 token。

于是 2.1 做了四件事（PDF p.1、p.5）：

1. **稠密预测损失**：看得见的块也进损失，离被遮区域越近权重越大；
2. **深层自监督**：不只在编码器出口，在中间三层也做同样的预测；
3. **多模态分词器**：图像走 2D 卷积、视频走 3D 卷积，不再把图片复制成静止视频；
4. **数据与模型放大**：图像从 100 万张换成 1.42 亿张，模型从 3 亿参数放到 20 亿。

摘要给出的结果（PDF p.1）：Ego4D 短时物体交互预期 7.71 mAP，EPIC-KITCHENS 动作预期 40.8 Recall@5，真机抓取成功率比 V-JEPA 2-AC 高 20 个百分点，Tartan Drive 导航 ATE 5.687，NYUv2 线性探针深度 0.307，SSv2 动作识别 77.7%。

如果只记一句话：

> **掩码预测如果只考缺掉的那一块，看得见的块就会去当寄存器；把它们按距离加权拉回损失，再让中间层一起受监督，稠密特征才会在最后一层上站稳。**

## 主要矛盾：全局已经够用，局部却站不住

要预判「下一秒会抓哪个杯子」，要让机械臂沿着相机深度方向伸过去夹住杯沿，要用一层线性层从特征图读出深度——模型至少要知道**每个图块对应画面上的哪一块、离镜头多远**。

两条自监督路线各占一半（PDF p.2）：

- **DINO 一系**的稠密特征质量高，检测、分割都好用，但它主要是图像模型，不直接从视频里学时间动态；
- **V-JEPA 一系**在表征空间做掩码去噪，运动理解和动作预期都强，还能接规划器做机器人控制，但局部结构读不出来。

2.1 要的是两边都要：局部结构站得住，同时不丢掉 2.0 已经会的全局运动。

## 先看全景：同一条 JEPA，改的是「考哪里」和「在哪些层考」

![V-JEPA 2.1 的完整架构：图像和视频分别经 2D 或 3D 卷积切块并加上模态嵌入，x 编码器只看可见 token 并输出多层表示，经 MLP 融合后与带位置的掩码 token 拼接，送进多层预测器；预测结果分别和 EMA 的 y 编码器多层输出比对，被遮 token 用普通 L1 预测损失，可见 token 用按距离加权的 L1 上下文损失。](/reports/V-JEPA-2.1/figure4-architecture.png)

图引自原文 Figure 4（PDF p.5）。上面一行是训练时的在线分支：切块、加模态嵌入、丢掉被遮的块，x 编码器 $E_\theta$ 处理看得见的块并吐出**多层**表示，MLP 融合降维后接上掩码 token，预测器 $P_\phi$ 为每个 token 吐出多层预测。下面一行是目标分支：EMA 编码器 $E_{\bar\theta}$ 看完整输入，给出同样多层的标准答案。右下两个损失框就是全文的核心：蓝色是新加的上下文损失，红色是 2.0 原有的预测损失。

评测时编码器一律冻住（PDF p.9）。所以后面所有分数衡量的都是表征本身，而不是微调能力。

## 核心设计一：稠密预测损失——看得见的块也要当考题

### 旧问题：只考被遮的块，可见 token 会抄近道

2.0 的目标是（PDF p.4，式 1）：

$$
L_{\mathrm{predict}}=\frac{1}{|M|}\sum_{i\in M}\bigl\|P_\phi\bigl(E_\theta(x),\Delta_y\bigr)_i-\operatorname{sg}\bigl(E_{\bar\theta}(y)_i\bigr)\bigr\|_1
$$

$M$ 是被遮位置的集合；$E_\theta(x)$ 只看剩下的块；$\Delta_y$ 是一组只带位置、不带内容的可学掩码 token；$E_{\bar\theta}(y)$ 是 EMA 编码器对完整输入的编码；$\operatorname{sg}$ 是停止梯度。人话版：**看得见的部分提供线索，看不见的部分当考题，标准答案是完整输入在表征空间里的样子。**

问题出在细节上。预测器其实为**每一个**输入位置都吐一个向量，包括看得见的上下文，但损失只看被遮的那些（PDF p.4）。可见 token 因此没有「你必须还像你这个位置」的压力。对降低预测损失最有利的做法，反而是把这些位置挪去攒全局信息，帮忙补被遮的块。

![V-JEPA 2 的特征图 PCA 是彩色噪点，加上上下文损失后，狗的头和身体、车身与车轮都被映成成片的一致颜色。](/reports/V-JEPA-2.1/figure3-context-loss-pca.png)

图引自原文 Figure 3（PDF p.4）。三行依次是原图、V-JEPA 2 的特征 PCA、加上上下文损失 $L_{\mathrm{ctx}}$ 后的特征 PCA。报告强调的是第三行里**同类部件被映到同一组主成分**：几只狗的头是同一种颜色，车轮是同一种颜色（PDF p.4）。这是定性证据，定量的在下面的表里。

### 新设计：给可见 token 也加一项，而且离缺口越近越重

![左图：V-JEPA 2 只有被遮住的紫色块进损失，看得见的块全是灰色；右图：V-JEPA 2.1 看得见的块也进损失，紧贴被遮区域的一圈绿色最深，越远越浅。](/reports/V-JEPA-2.1/figure-context-weight.svg)

这张讲解图据式 1–3（PDF p.4–7）画，是机制示意。2.1 把同样形式的 L1 损失套到可见集合 $C$ 上（PDF p.5，式 2）：

$$
L_{\mathrm{ctx}}=\frac{1}{|C|}\sum_{i\in C}\lambda_i\bigl\|P_\phi\bigl(E_\theta(x),\Delta_y\bigr)_i-\operatorname{sg}\bigl(E_{\bar\theta}(y)_i\bigr)\bigr\|_1
$$

总损失 $L_{\mathrm{dense}} = L_{\mathrm{predict}} + L_{\mathrm{ctx}}$（PDF p.7）。关键在权重 $\lambda_i$。报告明说：天真地对所有可见 token 加同样的损失，系统会找到平凡解，比如直接把上下文特征复制过去，全局语义任务就垮了（PDF p.7）。Table 2 把这条取舍量了出来（PDF p.7，ViT-L 主阶段）：

| $\lambda$ | 方案 | 预热 | ADE20K mIoU | SSv2 Acc. |
|---|---|---|---:|---:|
| 0（即 V-JEPA 2） | 常数 | 否 | 22.2 | 72.8 |
| 0.05 | 常数 | 否 | 26.4 | 71.0 |
| 0.2 | 常数 | 否 | 29.6 | 62.5 |
| 0.5 | 常数 | 否 | 27.5 | 53.8 |
| 1.0 | 常数 | 否 | 24.6 | 51.1 |
| 0.2 | 常数 | 是 | 30.5 | 60.5 |
| 0.5 | 常数 | 是 | 32.2 | 61.5 |
| 0.5 | 按距离加权 | 是 | **33.8** | **62.5** |

读这张表只要看三件事：

1. **常数 $\lambda$ 一路加大，分割先升后降，动作识别一路掉。** $\lambda = 1$ 时 SSv2 掉到 51.1，分割也回落到 24.6——可见 token 的监督不能无节制。
2. **在第 50–100 个 epoch 把 $\lambda$ 慢慢升上去**，报告说能大幅稳定训练，并救回一部分动作识别（PDF p.7）。
3. **最终方案按距离加权**（PDF p.7，式 3）：

$$
\lambda_i=\frac{\lambda}{\sqrt{d_{\min}(i,M)}}
$$

$d_{\min}$ 是这个上下文 token 到最近被遮 token 的距离，以「块数」计。离缺口近的位置权重大，逼模型在「看得见」与「看不见」的交界处把局部连续性接上（PDF p.7）。附录里 $\lambda$ 视频取 0.5、图像取 0.7（PDF p.33）。报告没写距离用哪种度量。

加权方案把 ADE20K 从 22.2 推到 33.9、NYUv2 从 0.682 降到 0.473（PDF p.5、p.7 正文）；Table 1 同一行是 33.8 与 0.474（PDF p.7），两处相差一位小数。

### 收益与代价

收益是局部结构出现了。代价同样写在 Table 1 第一跳：SSv2 从 72.8 掉到 62.5，ImageNet 从 82.2 掉到 72.6（PDF p.7）。**稠密和全局在这一步是打架的。** 如果停在这里，2.1 只是拿动作识别换分割，不算解。

### 可迁移启发

发现表征「全局很强、局部很糊」时，先问损失有没有漏掉某些位置，而不是先加参数。**没进损失的位置会被挪作他用，这不是实现瑕疵，是目标函数允许的合法解。** 任何掩码、稀疏、检索系统都可以问同一句：没被考的那些槽位，是不是在偷偷当草稿纸？

## 核心设计二：深层自监督——让局部信息有一条走到出口的路

### 旧问题：上下文损失只在出口考

上下文损失把局部结构逼了出来，分类却掉了。报告没有单独解释分类为什么掉。**我们的理解是**：局部信息和全局信息都只在最后一层这一处接受监督，二者抢同一份容量；中间层没有任何信号告诉它们「局部信息要一路保留下去」。下面附录 D.1 那张表支持这个读法。

### 新设计：中间三层加出口层，四层一起考

做法（PDF p.7）：

1. 从 x 编码器取出三个中间块的输出，加上最后一层，沿通道维拼起来；
2. 一个轻量 MLP 融合并降维，送进预测器；
3. 预测器吐出对应这四层的四份预测；
4. 预测损失和上下文损失在四层上**各算一遍**。

ViT-G 取的四层是第 12、24、36、48 块（PDF p.33）；附录说这四层等距分布，由此推断 ViT-G 有 48 块（本文推断，报告没另给宽度与头数）。为此预训练预测器从 V-JEPA 2 的 12 块加深到 24 块，隐维 384（PDF p.33）。

### 收益：分类捞回来，分割继续涨

Table 1 的第二跳（PDF p.7）：

| | IN1K | SSv2 | NYU RMSE ↓ | ADE20K |
|---|---:|---:|---:|---:|
| + 上下文损失 | 72.6 | 62.5 | 0.474 | 33.8 |
| + 多层预测（深层自监督） | 80.8 | 72.1 | 0.463 | 38.6 |

正文写 SSv2 回到 72.0（PDF p.8），表里是 72.1。

更能说明「为什么有效」的证据在附录 D.1（PDF p.37，Table 13）。拿从头训的 ViT-L 问：下游探针只用最后一层，和拼四层，差多少？

| 深层自监督 | ADE20K 末层 | ADE20K 四层 | NYU 末层 ↓ | NYU 四层 ↓ | Diving-48 末层 | Diving-48 四层 |
|---|---:|---:|---:|---:|---:|---:|
| 无 | 34.9 | 39.1 | 0.513 | 0.463 | 85.8 | 86.9 |
| 有 | 42 | 43.9 | 0.381 | 0.370 | 87.2 | 88.1 |

没有深层自监督时，局部信息其实在网络里，只是**留在中间层**：分割要拼四层才从 34.9 升到 39.1。有了深层自监督，最后一层自己就到了 42，拼四层只再多 1.9。报告的解释是：训练信号让局部信息一路流到了最后几层，下游不必再回头去取中间层（PDF p.7–8、p.37）。主结果里的深度与分割也明确只用冻住编码器的最后一层（PDF p.15）。

### 代价与可迁移启发

代价是预训练时预测器更重（24 块）。但蒸馏小模型时，预测器退回 12 块，而且不做深层自监督（PDF p.9、p.34）——多层预测是训练期的脚手架，不是部署时要带着的结构。

可迁移的一点：**在出口加了一项很「局部」的损失、全局指标却掉了，先试着把同一项损失沿深度多铺几层，而不是把局部损失关掉。**

## 核心设计三：图像和视频不要再假装是同一种输入

V-JEPA 2 用同一个 3D 卷积切块，图像被沿时间复制成 16 帧「静止视频」（PDF p.8）。报告说这有两处不好：算力白白翻倍；表征上等于告诉模型「图片就是一段完全不动的视频」，引入错误的偏置。

2.1 的多模态分词器（PDF p.8–9）：

- 视频：16×16×2 的 3D 卷积（空间 16 像素，时间 2 帧）；
- 图像：16×16 的 2D 卷积；
- 编码器和预测器的输入都加一个可学的**模态 token**，标明这是图还是视频，帮模型区分图像里更强的静态外观线索和视频里的运动信息。

Table 1 里这一跳很小：ADE20K 40.8 → 41.4，分类不变（PDF p.7、p.9）。它的价值不在刷分，而在让两种模态按各自的形态进来。后面的 Ego4D 探针同时吃一段 384 像素的低分辨率视频和一张 1080 像素的最后一帧，两条分词器各走各的（PDF p.10），就是这一设计的直接用处。

可迁移的一点：联合训练图像与视频时，别图省事把静帧当成「时间维为 1 的视频」。多花一个 2D 卷积加一个模态嵌入，比事后用数据增强假装有运动干净得多。

## 核心设计四：换数据，再把模型放大到 20 亿

### 数据：100 万张 ImageNet 换成 1.42 亿张 LVD-142M

VisionMix163M 对 V-JEPA 2 的 VideoMix22M 做了两处替换（PDF p.8，Table 3）：

| 来源 | 样本数 | 类型 | 总时长 | V-JEPA 2 权重 | V-JEPA 2.1 权重 |
|---|---:|---|---:|---:|---:|
| SSv2 | 168K | 第一人称视频 | 168 小时 | 0.056 | 0.170 |
| Kinetics | 733K | 第三人称视频 | 614 小时 | 0.188 | 0.010 |
| HowTo100M | 1.1M | 第三人称视频 | 134K 小时 | 0.318 | 0.100 |
| ImageNet | 1M | 图像 | — | 0.250 | 0 |
| YT-1B | 19M | 第三人称视频 | 1.6M 小时 | 0.188 | 0.720 |
| LVD-142M | 142M | 筛选过的图像 | — | 表中空白 | 表中空白 |

用意很直白：1.42 亿张图已经覆盖了大量静态视觉概念，视频就可以少看 Kinetics，多看运动丰富的 SSv2 和更杂的 YT-1B（PDF p.8）。

图像与视频不在同一个批次里混：不同 worker 各管一种模态，每轮迭代后把两边的梯度加起来再更新。图与视频的比例靠各自的批大小控制，经验最优是每个全局批次 128 段 16 帧视频加 2304 张图（PDF p.8）。所以 LVD-142M 那一格权重空着——图像占比由批大小决定，不在这张采样权重表里。

这一跳在 Table 1 上全面小涨：SSv2 72.1 → 72.6，IN1K 80.8 → 81.6，ADE20K 38.6 → 40.8，NYU 0.463 → 0.418（PDF p.7–8）。

### 模型：ViT-L 3 亿到 ViT-G 20 亿，再加高分辨率降温

Table 1 把最后两跳写得很清楚（PDF p.7、p.9）：

整个配方的顺序值得记：**先改目标，再用深层监督把全局捞回来，然后才配得上更大的数据和模型。** 报告没有做反过来的对照（先放大、损失仍只考被遮块），所以不能说「放大自然会出稠密特征」。能分开看的是：同一个 ViT-L 上，前四跳已经把 ADE20K 从 22.2 推到 41.4。

## 蒸馏：放大到 20 亿，是为了把能力压回小模型

报告明说，放大到 ViT-G 不只为了拿到最好成绩，也为了能有效蒸馏（PDF p.9）。蒸馏协议相对预训练改了四处（PDF p.9、p.34）：

1. EMA 目标编码器换成冻住的 ViT-G 老师；
2. 学生另外维护一份 EMA 副本，不进损失，只作为最终导出的模型；
3. 损失形式不变，但只算在老师最后一层上，不做深层自监督；
4. 重新训一个只有 12 块的预测器，最后一层对齐老师的维度，不继承预训练预测器。

老师分两阶段：低分辨率主阶段用降温前的 ViT-G，高分辨率降温阶段用降温后的 ViT-G；第二阶段的学生从第一阶段的 EMA 学生初始化。报告说这比单阶段、或始终蒸最终的高分辨率老师都好（PDF p.34），但没给对照数字。

## 结果一：短时预期，稠密特征最先兑现的地方

### 任务

Ego4D 短时物体交互预期（Short-Term object interaction Anticipation，STA）要同时给出四件事（PDF p.9–10，Figure 6）：下一秒要交互的物体框、物体名词、动作动词、距离接触还有几秒（记作 $\delta$）。数据是 Ego4D STA v2 划分，243 小时，128 个名词类、81 个动词类，训练 98,276 条、验证 47,395 条（PDF p.10）。

指标是 Top-5 AP 与 Top-5 mAP，框的 IoU 要大于 0.5；最严格的 mAP All 还要求名词、动词都对，接触时间误差在 0.25 秒以内。因为未来本来就不唯一，每个样本最多不惩罚四个得分最高的假阳性（PDF p.10）。

### 探针

编码器冻住。低分辨率视频走 3D 分词器，最后一帧的高分辨率图走 2D 分词器，各加各的模态嵌入（PDF p.10）。视频特征过四层注意力探针，再用「帧引导的时间池化」把 3D 的视频 token 对齐到最后一帧的 2D 网格，和图像特征相加，拉成多尺度特征金字塔，送进和 StillFast 相同、在 Faster R-CNN 上加了动词与接触时间分支的检测头（PDF p.10、p.35）。

输入长度在正文与附录不一致：正文写 384 像素、8 帧、跨 0.5 秒的视频（PDF p.10）；附录 C.4 写最终最佳配置是 16 帧、384 像素、每秒 2 帧（PDF p.35）。两处并存，本文不合成一个。

### 结果

Table 4 摘几列（PDF p.11）：

| 模型 | AP 框 | AP 框+动词 | AP 框+$\delta$ | mAP N+$\delta$ | mAP All |
|---|---:|---:|---:|---:|---:|
| STAformer | 38.3 | 16.6 | 12.27 | 9.94 | 5.67 |
| DINOv3 ViT-7B（同协议） | 50.2 | 23.8 | 14.2 | 10.3 | 5.68 |
| V-JEPA 2 ViT-g（同协议） | 45.7 | 22.2 | 16.7 | 10.4 | 6.02 |
| V-JEPA 2.1 ViT-g | 47.3 | 23.6 | 18.1 | 11.4 | 6.75 |
| V-JEPA 2.1 ViT-G | **50.7** | **25.8** | **20.2** | **12.8** | **7.71** |

7.71 相对此前最好的 STAformer（5.67）约高 35%，报告就是这么算的（PDF p.11）。注意 Figure 2 把「+35%」标在 V-JEPA 2 与 2.1 两根柱之间（PDF p.2），而相对 V-JEPA 2 的 6.02 实际约高 28%（本文除法）。正文还写了一个「12.9 mAP b+δ」（PDF p.11），表里对应格是 12.8。

这张表的真正看点是**两条对照线的分工**：DINOv3 ViT-7B 的框 AP 50.2 和 2.1 的 50.7 几乎一样，说明「会框」这件事图像模型也做得好；但 DINOv3 的接触时间（AP 框+$\delta$ 14.2）明显弱于 2.0 与 2.1，于是 mAP All 只有 5.68。报告把 2.1 的增益主要归到「下一个动作」和「接触时间」上（PDF p.11）。**稠密定位加上视频预测，才是这道题的完整答案。**

## 结果二：动作预期，同尺寸没赢，2B 才拉开

EPIC-KITCHENS-100：100 小时、45 个厨房的第一人称做饭视频，3568 种「动词 + 名词」动作；默认在动作开始前 1 秒预测，指标是按类平均的 Recall@5（PDF p.12）。探针沿用 V-JEPA 2：上下文视频进编码器，预测器拿掩码 token 预报 1 秒后那一帧的表征，编码器与预测器的输出拼起来进注意力探针，三个查询分别分类动作、动词、名词，用焦点损失（PDF p.12、p.36）。上下文是 32 帧、每秒 8 帧、384×384（PDF p.12）。

Table 5（PDF p.12）：

| 方法 | 参数 | 动词 | 名词 | 动作 |
|---|---:|---:|---:|---:|
| PlausiVL | 8B | 55.6 | 54.2 | 27.6 |
| V-JEPA 2 ViT-g | 1B | 63.6 | 57.1 | 39.7 |
| V-JEPA 2.1 ViT-g | 1B | 63.6 | 56.2 | 38.4 |
| V-JEPA 2.1 ViT-G | 2B | **64.3** | **59.9** | **40.8** |

必须读细：**同为 1B，2.1 的动作 Recall 38.4 低于 2.0 的 39.7。** 报告自己的说法是「同尺寸可比，放大到 2B 才拉开」（PDF p.12）。摘要里的 40.8 是 ViT-G 的数，相对 2.0 高 1.1 分、即相对提升 2.8%（PDF p.12）。

## 结果三：真机抓取，深度更准，伸得到位

2.1 没有重写规划器。它用 V-JEPA 2 的公开代码，把特征换成 2.1 的视频编码器，训一个同样 24 层、约 3 亿参数的帧级因果动作条件预测器；数据是 Droid 原始数据集，损失是教师强制加两步 rollout（PDF p.12）。部署在实验室里的 Franka Panda 桌面机械臂加平行夹爪上，零样本，给一张目标图，用模型预测控制（MPC）规划，任务配置文件与 V-JEPA 2 完全相同（PDF p.12–13）。

Table 6（PDF p.13），单张 A100 用交叉熵方法（CEM）优化动作，每种技能评 10 个任务取平均：

| 方法 | 样本数 | 迭代 | 规划步长 | 每步耗时 | 到达 | 抓取 | 抓放 |
|---|---:|---:|---:|---|---:|---:|---:|
| V-JEPA 2 | 800 | 10 | 1 | 3 秒 | 100% | 60% | 80% |
| V-JEPA 2.1 | 800 | 10 | 1 | 3 秒 | 100% | 70% | 80% |
| V-JEPA 2.1 | 300 | 15 | 8 | 14 秒 | 100% | 80% | 80% |

同一套规划超参下，抓取从 60% 到 70%；把规划步长拉到 8、样本降到 300，再到 80%（PDF p.13）。摘要说的「+20%」指的就是抓取 60% → 80%，抓放两边都是 80%。报告给出的原因是 2.1 更好地编码了深度，而抓杯子需要沿相机深度方向规划动作（PDF p.13，Figure 8）；并且 2.1 能从更长的规划步长里获益，而 2.0 在更长步长下成功率反而下降（PDF p.13）。

失败模式写得很干净：2.1 在抓取和抓放上的失败，来自夹爪动作规划——夹得太早、搬运途中微微张开导致掉落——不是空间理解出错（PDF p.13）。**稠密特征解决的是「伸到哪」，不是「手指何时合拢」。**

## 结果四：导航，表征好用了，规划快十倍

短时导航沿用 NWM 的设定：给最近一帧观测和一张目标图，预测 2 秒轨迹（PDF p.14）。在 2.1 的表征上训一个条件扩散 Transformer（CDiT）。直接在 2.1 的高维嵌入里做扩散不好训：维度至少是 SD-VAE 潜空间的 80 倍，随手加的噪声很容易把样本推离数据流形（PDF p.14）。两处改动：预测干净表征而不是噪声；采样用更少随机性的 DDIM 而不是 DDPM。

规划用 CEM：采样 480 条 2 秒、每秒 4 帧的候选轨迹，在平移加偏航的 3 自由度空间里搜，用世界模型模拟后挑离目标嵌入最近的一条。2.1 只需 8 步去噪，SD-VAE 那条最优设定至少要 128 步（PDF p.14）。

Table 7（PDF p.14），开环规划：

| 模型 | 规划耗时 | Recon ATE | Tartan Drive ATE | SCAND ATE | SACSoN ATE | 平均 ATE | 平均 RTE |
|---|---:|---:|---:|---:|---:|---:|---:|
| NWM | 103.2 秒 | 1.146 | 5.831 | 1.113 | 4.037 | 3.032 | 0.696 |
| V-JEPA 2.1 ViT-g | 10.6 秒 | 1.146 | 5.758 | 1.094 | 3.904 | 2.975 | 0.690 |
| V-JEPA 2.1 ViT-G | 10.6 秒 | 1.179 | 5.687 | 1.038 | 4.054 | 2.990 | 0.688 |

摘要的 5.687 是 ViT-G 在 Tartan Drive 上的 ATE。换一个数据集看，结论并不整齐：ViT-G 在 Recon 和 SACSoN 上比 NWM 差，平均 ATE 反倒是 ViT-g 最好。所以准确的说法是报告自己那句「10 倍提速、不牺牲性能」（PDF p.14），而不是「全面更准」。这是开环验证集上的轨迹误差，不是真车闭环。

## 结果七：视频问答不是主场

2.1 同样把冻住的视频编码器接到 Llama 3.1 8B 上做视频大模型（PDF p.19）。数据是 PerceptionLM 的公开子集，经过领域过滤、图文错位过滤，再用 Qwen3VL 当质量裁判，丢掉 18%，只过滤不改写（PDF p.20）。对齐沿用 V-JEPA 2 的三阶段，再加一个把上下文扩到 64 帧的第四阶段（2.0 是 32 帧）（PDF p.20）。

## 限制与未公开信息

论文没有单独的局限性一节，边界散在结果和未来工作里：

- **同尺寸不一定赢 2.0。** ViT-g 上 SSv2 76.9 对 77.3，EK100 38.4 对 39.7。稠密配方在 1B 时付出一点全局代价，要到 2B 才全面追平或超过。
- **分割与跟踪仍落后最好的图像自监督模型。** ADE20K、Cityscapes、DAVIS、YouTube-VOS 都低于 DINOv3；原因只有假说，没有数据消融。
- **机器人侧，空间对了，夹爪仍会失手。** 抓放没有比 2.0 更高；失败出在开合时机。
- **导航是开环、短时、3 自由度**，并且不是每个数据集都更准。
- **视频问答不是主场**，短视频运动类基准反而更弱。
- **几处表与正文不一致**：上下文损失的 33.9 与 33.8、SSv2 的 72.0 与 72.1、STA 输入帧数、蒸馏段的 67.0、Table 14 与 Table 8 的 VOS 数、SSv2 探针输入规格。
- **没公开的**：预训练用了多少卡、多长墙钟时间；距离加权用的是哪种距离；上下文损失预热的具体曲线；两阶段蒸馏相对单阶段的对照数字。

未来工作只列了三条（PDF p.24）：模型从 1B、2B 继续往 7B 放大；继续扩大数据；在稠密表征上做世界模型，点名 DINO-Foresight 与 Back to the Features。**论文自己把「稠密世界模型」写成还没做的事**：本篇的机器人与导航实验，是把 2.0 的规划配方换上更好的编码器，不是新的规划算法。

## 可迁移启发

1. **损失没打到的位置，会被挪作他用。** 2.0 不是不会编码局部，是目标函数允许可见 token 去当寄存器。设计任何掩码或稀疏目标时，先列一遍「哪些位置没被考」。
2. **靠近缺口的位置，权重要大于远离缺口的位置。** 均匀的 $\lambda = 1$ 把 SSv2 打到 51.1；按 $1/\sqrt{d_{\min}}$ 加权，把监督集中在看得见与看不见的交界处，两头都更好。
3. **局部损失伤了全局指标时，先沿深度铺，再考虑关。** 深层自监督把 SSv2 从 62.5 捞回 72.1，分割还继续涨。
4. **比较稠密能力，要把「用哪几层」写进协议。** 没有深层自监督时，信息在中间层；有了之后，最后一层就够。只看最后一层的线性探针，测的是「好不好取」，不是「有没有」。
5. **图像和视频的切块应该分开。** 时间复制是假的联合训练，还浪费算力；2D 与 3D 两条分词器让下游可以同时吃低分辨率视频和高分辨率静帧。
6. **配方先改对，放大才有意义。** 同一个 ViT-L 上，前几跳已经把 ADE20K 从 22.2 推到 41.4；20 亿参数与 1.42 亿张图是在改对的目标上继续涨。
7. **大模型的一个用途是当老师。** 蒸出来的 3 亿参数 ViT-L 贴近 20 亿的老师，8000 万的 ViT-B 在全局任务上超过从头训的 ViT-L。

## 关键词回看

- **上下文 token**：掩码后仍可见的图块。2.0 不监督它们，2.1 认为这正是稠密特征糊掉的原因。
- **寄存器现象**：不受监督的 token 被挪去攒全局信息，自身不再代表它所在的位置。
- **稠密预测损失**：$L_{\mathrm{predict}} + L_{\mathrm{ctx}}$，可见位置按 $\lambda/\sqrt{d_{\min}}$ 加权。
- **深层自监督**：编码器中间三层加最后一层一起做预测，让局部信息流到出口。
- **多模态分词器**：图像 2D、视频 3D，再加模态 token。
- **VisionMix163M**：LVD-142M 图像加重新配比的视频；图和视频分 worker 训练、合并梯度。
- **高分辨率降温**：最后 12,000 步学习率下降，视频升到 64 帧、384，图像升到 512。
- **STA**：短时物体交互预期，要框、名词、动词和接触时间。
- **V-JEPA 2-AC**：V-JEPA 2 的动作条件预测器与规划配方；2.1 只换编码器。
- **CDiT**：条件扩散 Transformer，本篇用它在 2.1 表征上做短时导航。
